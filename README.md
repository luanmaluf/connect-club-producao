# CONNECT CLUB — Produção Executiva

Dashboard e orçamento colaborativo para o evento CONNECT CLUB.

## Recursos
- Dashboard financeiro automático.
- Custo projetado, contratado, pago e saldo a pagar.
- Receita potencial, taxas, comissões e lucro esperado.
- Break-even em número de ingressos, respeitando a ordem dos lotes.
- Cadastro, edição e exclusão de qualquer item de produção.
- Fornecedor, responsável, prioridade, status, observações e datas.
- Lotes de ingressos e receitas extras/patrocínios editáveis.
- Histórico de alterações.
- Backup/restauração em JSON.
- Modo compartilhado por link.

## Compartilhamento
O botão **Ativar link compartilhado** cria, pelo navegador, uma base JSON remota em jsonstorage.net e acrescenta o endereço dessa base ao link do site. Quem receber o link poderá ler e editar a mesma base.

Este modo é aberto: quem tiver o link tem acesso de edição. Não use para dados sensíveis.
